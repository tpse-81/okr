User documentation
==================

This section explains how to use the OKR tool as an end user.
It is written for both regular project members and team leads.

If you are looking for installation, configuration, or maintenance instructions,
see the administrator documentation instead.

Recommended reading path
------------------------

If you are new to the tool, read the pages in this order:

1. :doc:`getting-started`
2. :doc:`navigation`
3. :doc:`work-in-a-project`
4. :doc:`projects-and-roles`

If you are a team lead, also pay attention to the team-lead notes on the project pages.

If you need help with account access or login security, see :doc:`account-security`.
If something behaves unexpectedly, check :doc:`faq`.
